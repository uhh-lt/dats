# DATS Report — Q4 2025 (October – December)

**Theme:** Consolidation — faster PDF processing, perspectives improvements, and stability

**Major contribution:** [Docling serve (#639)](https://github.com/uhh-lt/dats/pull/639) — faster, simpler PDF conversion via an external Docling service.

## Summary

A quieter consolidation quarter after the big Q3 refactor. PDF conversion was switched to Docling-serve, resulting in less code and faster conversion. The perspectives feature received improvements and bugfixes, classifier training memory usage was reduced by chunking long documents, and preprocessing recomputation became more robust with retries.

## Detailed breakdown

- [#639](https://github.com/uhh-lt/dats/pull/639) **Docling serve** — switched PDF conversion to an external Docling service for less code and faster conversion.
- [#643](https://github.com/uhh-lt/dats/pull/643) **Perspectives improvements** — bugfixes and improved cluster naming/descriptions.
- [#632](https://github.com/uhh-lt/dats/pull/632) **Classifier training memory** — reduced (span) classifier training memory by chunking long documents.
- [#640](https://github.com/uhh-lt/dats/pull/640) **Retry recompute preprocessing** — more robust preprocessing recomputation.
- [#644](https://github.com/uhh-lt/dats/pull/644) **Cultcryo bugfixing** — project-specific bugfixes.
