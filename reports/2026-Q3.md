# DATS Report — Q3 2026 (July – August)

**Theme:** Annotator UX polish and classifier improvements

**Major contributions:**

- [Code shortcuts (#696)](https://github.com/uhh-lt/dats/pull/696) — keyboard-driven rapid annotation.
- [Annotation resizing (#698)](https://github.com/uhh-lt/dats/pull/698) — resize span, sentence, and bbox annotations.
- [Bifrost integration (#685)](https://github.com/uhh-lt/dats/pull/685) — LLM gateway integration.

## Summary

This quarter was dominated by annotator user-experience improvements: per-user, per-project code shortcuts bound to digit keys for rapid annotation, resizing of span/sentence/bbox annotations, memo indicators across all entity types, a reworked annotation toolbar, and aligned sentence & span annotator behavior with better highlighting and performance. The classifier system received several refinements, including a training-signal-strength indicator. The LLM assistant gained a new result step surfacing erroneous prompts and responses, Bifrost was integrated, multiple OIDC providers became configurable, and a "What's New" dialog based on GitHub release notes was added.

## Detailed breakdown

### Annotator UX

- [#696](https://github.com/uhh-lt/dats/pull/696) **Code shortcuts** — per-user, per-project code bindings on digit keys (0–9) for quick annotations.
- [#708](https://github.com/uhh-lt/dats/pull/708) **Shortcut improvements** — ordered shortcuts (1,2,3,…,0) and hidden while searching codes.
- [#698](https://github.com/uhh-lt/dats/pull/698) **Annotation resizing** — resizing for span, sentence, and bbox annotations.
- [#699](https://github.com/uhh-lt/dats/pull/699) **Memo indicators** — tags, codes, sdocs, and annotations now clearly indicate attached memos.
- [#700](https://github.com/uhh-lt/dats/pull/700) **Annotation toolbar** — clearer section separation and new icons.
- [#703](https://github.com/uhh-lt/dats/pull/703) **Annotator alignment** — aligned sentence & span annotator functionality, proper highlighting, jump-to-annotation, and performance improvements.
- [#701](https://github.com/uhh-lt/dats/pull/701) **Pending annotation fix** — disabled interactions with fake/pending annotations.
- [#704](https://github.com/uhh-lt/dats/pull/704) **Code enabling fix** — enabling a code now enables all its parents.
